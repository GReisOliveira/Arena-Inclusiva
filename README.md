# Arena Inclusiva

## Sobre o Projeto
O **Arena Inclusiva** (baseado no escopo "Esporte Sem Limites") é um projeto acadêmico de Front-End desenvolvido para o Curso Superior de Informática da UNICID. O objetivo do site é centralizar informações sobre esportes adaptados, ajudando pessoas com deficiência a descobrirem modalidades que combinem com seu perfil, além de promover inclusão social, saúde e autoestima.

A ideia central do projeto é que o usuário possa criar uma conta, responder a um questionário e receber recomendações personalizadas de esportes com base em suas características.

## Status Atual
Neste momento, o projeto encontra-se na fase de **protótipo estrutural e visual da Página Inicial (`index.html`)**. 

O que já está pronto neste arquivo:
*   **Estrutura em HTML5:** Semântica básica da página inicial.
*   **Estilização em CSS3:** Identidade visual aplicada diretamente no arquivo (cores, tipografia, botões e layout).
*   **Responsividade:** O layout se adapta a computadores, tablets e celulares.
*   **Prévia de Conteúdo:** Exibição de como será a vitrine de esportes recomendados.

O que **não** está incluído nesta etapa (previsto para o futuro):
*   As outras 9 páginas descritas no escopo do projeto (Sobre, Esportes, Impacto, etc.).
*   O uso de JavaScript para a lógica do questionário, sistema de login e filtragem real dos esportes.

## Tecnologias Utilizadas
*   HTML5
*   CSS3 (Flexbox, Grid e Variáveis CSS)

## Como visualizar
Como o projeto atualmente é composto por arquivos estáticos simples, basta fazer o download do arquivo `Arena Inclusiva.html` e abri-lo em qualquer navegador de internet moderno (como Chrome, Firefox ou Edge). Não é necessário instalar nenhum servidor ou dependência.
